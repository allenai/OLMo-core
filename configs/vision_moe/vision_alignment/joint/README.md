# Joint phase profiles

No production profile is checked in yet. In addition to all perception-phase artifacts, joint
continued pretraining requires an approved permanent perception checkpoint and a data-owner
reviewed 950-object s002 token-count/SHA-256 inventory. That inventory must be pinned in the
native replay builder before train/holdout manifests and their verification receipt can be
created.

The language model is unfrozen only in this phase, so native replay and its disjoint holdout are
mandatory; Tulu or chat-formatted text is not an allowed replacement.
