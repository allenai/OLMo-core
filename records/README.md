for agents, and setup notes. These are *reference documents* — still-valid knowledge, unlike
`deprecated/` (things that must not be used). New writeups of this kind go here, not the repo
root; the root keeps only README/CHANGELOG/CONTRIBUTING/CLAUDE.md/local_cluster.md/beaker.md.

- [layer-soft-probe.md](layer-soft-probe.md) — **"soft layers": does the pooled-doc soft token have to be applied at EVERY layer?** (eval only, 2026-09-14). Per-layer choice between the full row and the compacted soft row on a fixed dense-trained Qwen3.5-4B. Headline: giving each pooled document a slot in **one** layer and removing it from the other 31 dominates today's all-layers scheme on fidelity *and* on FLOPs *and* on memory (contradiction @8k EM 0.730±0.032 vs 0.415±0.035; @32k 0.250±0.055 vs 0.078±0.034). Also: the top quarter of layers can be compacted at parity with full attention; a read-then-compress cut at layer 7–14 is catastrophic and unexplained; ultra-pooling the *kept* docs is free on oolong and impossible on contradiction. ⚠ probe sizes (eval_size 200 / 64).
